MediQuick AI

MediQuick AI is an AI-powered emergency hospital recommendation system designed to predict emergency-room congestion and waiting times by combining historical demand, traffic, weather, and community feedback to support faster, data-informed hospital selection.

GitHub Repository ↗Back to Projects
01 / Overview

Project Overview

A predictive healthcare decision-support prototype combining multiple real-world signals to estimate hospital congestion, compare options, and provide explainable recommendations.

Problem

Emergency departments can experience unpredictable demand, traffic conditions, and waiting times. MediQuick AI explores how these signals can be combined to reduce uncertainty when comparing nearby hospitals.

Approach

The system combines emergency demand, traffic, weather, and community feedback with machine-learning models and a large language model to predict, rank, and explain hospital recommendations.

Implementation

The project is designed around a modern AI application stack including a web or mobile interface, FastAPI services, PostgreSQL, predictive ML models, Gemini, mapping and weather APIs, Docker, and cloud infrastructure.
