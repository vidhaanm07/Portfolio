MediQuick AI

MediQuick AI is an AI-powered emergency hospital recommendation system that predicts ER congestion and waiting times by combining historical demand, traffic, weather, and community feedback—helping users identify the hospital with the fastest expected time to treatment

GitHub Repository ↗ Back to Projects
01 / Overview

About the Project

What it does: AI-powered hospital recommendation based on predicted ER congestion and total treatment time. Problem: Reduces uncertainty around emergency wait times, overcrowding, and treatment delays. Approach: Combines ER demand, traffic, weather, and community data using XGBoost/LightGBM + Gemini to predict, rank, and explain the best nearby hospital

Implementation: Built with React/Flutter, FastAPI, PostgreSQL, XGBoost/LightGBM, Gemini, Google Maps, OpenWeather, Docker, and cloud infrastructure. Objectives: Predict ER congestion, reduce treatment delays, improve hospital selection, and support better resource utilization. Results: Developed an MVP prototype demonstrating AI-based hospital ranking and explainable recommendations using multiple real-world data signals
